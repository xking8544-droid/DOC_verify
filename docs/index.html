SECURITY ARCHITECTURE

How Fake Applications Are Eliminated

3-Tier Verification Pipeline ensuring zero fake certificates are issued

1. Coordinator Roster Match

Claims are automatically cross-checked against official attendance sheets in the event_roster table. Unlisted claims are flagged instantly.

2. Faculty Verification

Department faculty reviews the submission, examines attached proof, and endorses authentic claims before sending to HOD.

3. SHA-256 via Java RMI

Approved certificates receive a 64-character SHA-256 cryptographic digest computed via remote Java RMI on port 1099.
