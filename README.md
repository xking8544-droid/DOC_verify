## Tech Stack
- Java 8+, JSP-Servlet (Tomcat 9)
- Bootstrap 5, MySQL
- RMI for SHA-256 cryptographic hashing
- JSTL, JDBC

## Setup Instructions
1. Install JDK 8+ and set JAVA_HOME
2. Install Apache Tomcat 9
3. Install MySQL 8.0
4. Run `sql/schema.sql` in MySQL
5. Copy `mysql-connector-j.jar` to `WEB-INF/lib/`
6. Deploy the project to Tomcat webapps
7. Access at http://localhost:8080/DocuVerify/
